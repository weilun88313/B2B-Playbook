# Roadmap

This roadmap is dated **2026-08-24** and reflects the repository's first public-product phase. The goal is not maximum page count; it is a trusted, executable B2B operating system that produces observable work for operators and AI agents.

## v0.1 — Establish the operating system

- [x] Reframe the README around an immediate result
- [x] Make English the canonical content language with a separate Chinese README introduction
- [x] Ship complete ICP, positioning, outbound, event-led growth, and enterprise-sales modules
- [x] Add a dependency-free ICP account scorer with tests
- [x] Add an installable Agent Skill entrypoint
- [x] Add structured feedback and automated repository validation
- [ ] Add a social preview image and repository topics in GitHub settings
- [ ] Publish the first GitHub Release after review

Suggested topics: `b2b`, `b2b-sales`, `sales`, `go-to-market`, `gtm`, `enterprise-sales`, `sales-playbook`, `agent-skills`, `templates`, `growth`.

## v0.2 — Evidence and field validation

- Add `Sources / Last verified / Confidence` to every complete module
- Add properly anonymized field cases alongside fictional teaching examples
- Record failures and “do not use when” cases, not only successful patterns
- Add a lightweight review label for field-validated playbooks
- Publish a public change log for corrected or expired guidance

## v0.3 — Complete the execution loop

- Event go / attend / skip scorer
- Enterprise-deal readiness checker
- Downloadable spreadsheet-friendly templates
- Complete the content and revenue-operations modules
- Searchable GitHub Pages documentation

## v1.0 — Trusted owner-maintained B2B operating system

- At least twenty field-validated cases with evidence boundaries
- Stable versioning and monthly releases
- A documented editorial update and evidence-review workflow
- Usage signals beyond stars: installs, forks, completed workflows, repeat readers, and actionable feedback

## What is deliberately out of scope

- Generic “growth hack” link dumps
- Purchased contact data or private customer lists
- Guaranteed conversion, pipeline, or revenue claims
- Legal advice presented as a checklist
- Tools that hide scoring logic behind an API

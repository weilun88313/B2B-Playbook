# Positioning metrics

## Track these

| Metric | How to use it |
|---|---|
| Message recall | Ask a new teammate or prospect to repeat what the product is for after one exposure |
| Qualified CTA rate | Qualified visitors or target accounts taking the intended next step / qualified visitors or accounts exposed |
| Alternative specificity | Opportunities where the current tool or process is named / qualified opportunities |
| Sales-language consistency | Calls or emails using the agreed trigger → alternative → result structure / reviewed sample |

## Do not count these as outcomes

- Finishing a messaging workshop
- Number of slogans created
- Homepage traffic without buyer quality
- A higher click-through rate caused by a vague curiosity headline

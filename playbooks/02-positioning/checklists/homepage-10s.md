# Checklist: homepage 10-second test

- [ ] A new visitor can identify the product category.
- [ ] The buyer or operating context is explicit.
- [ ] The current alternative is named or recognizable.
- [ ] The business result is more prominent than the feature list.
- [ ] The page gives one clear next step.
- [ ] The hero does not depend on undefined superlatives.
- [ ] Proof is specific and verifiable.
- [ ] A likely blocker can find the relevant constraint: security, data, deployment, integration, or implementation effort.
- [ ] The same positioning can open a sales conversation or demo.

# Checklist: pilot

- [ ] The buyer stated what happens and when if the pilot succeeds.
- [ ] Procurement, security, legal, implementation, and signatory seats are identified.
- [ ] The champion co-wrote the success criteria.
- [ ] Three concrete user tasks are defined.
- [ ] Three to four appropriate operators are committed.
- [ ] The executive sponsor is not treated as a product user.
- [ ] Setup work is minimized and owned.
- [ ] The pilot duration matches the technical need.
- [ ] A long integration pilot is paid when appropriate.
- [ ] Task completion and observed outcomes—not logins—drive the review.
- [ ] The seller knows the stop condition.

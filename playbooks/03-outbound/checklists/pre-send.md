# Checklist: pre-send

- [ ] The account passes the ICP and has no hard disqualifier.
- [ ] The target buying-committee seat is explicit.
- [ ] The trigger is observable and current.
- [ ] The first line can be verified.
- [ ] Personalization is not inferred from private or unverifiable data.
- [ ] The message names the crack in the current alternative.
- [ ] The claim uses approved proof only.
- [ ] The next step is specific and proportional to the evidence.
- [ ] The message still works when read on a phone.
- [ ] The close-the-loop touch is already planned.

# Checklist: after the event

- [ ] Every qualified conversation has a written context note.
- [ ] Contextual follow-up is sent within 48 hours.
- [ ] The next step is tied to the buyer's decision calendar.
- [ ] Missing buying-committee seats have discovery actions.
- [ ] Unqualified badges are downgraded rather than entered as opportunities.
- [ ] Complaints, opt-outs, and deletion requests are processed.
- [ ] Event metrics separate targets, meetings, conversations, and opportunities.
- [ ] The review records one change for the next event.

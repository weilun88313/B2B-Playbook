# Checklist: before the event

- [ ] The event has a completed go / attend / exhibit / skip score.
- [ ] Hard disqualifiers have been applied to the account list.
- [ ] Every target record has a labeled source.
- [ ] T1 and T2 accounts receive different research effort.
- [ ] Priority buying-committee seats are identified.
- [ ] Outreach references a real event context and observable trigger.
- [ ] The pre-booked qualified-meeting goal is explicit.
- [ ] Owners, calendars, meeting locations, and handoffs are assigned.
- [ ] The on-site note format is ready before travel.
- [ ] Data-source, outreach, and privacy requirements have been reviewed.

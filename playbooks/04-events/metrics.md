# Event metrics

## Track these

| Metric | Meaning |
|---|---|
| ICP density | Qualified target accounts / accounts reviewed for the event |
| Pre-booked meetings | Qualified meetings scheduled before opening day |
| Qualified conversation rate | Conversations with a real job, timing, and next step / substantive conversations |
| 48-hour follow-up completion | Qualified conversations with contextual follow-up in 48 hours / qualified conversations |
| Committee expansion | Conversations that reveal another buying seat / qualified conversations |
| Event-sourced progression | Qualified event opportunities reaching the next buyer action within the review window |

## Do not count these as outcomes

- Foot traffic
- Badge scans
- Giveaways distributed
- Social impressions without target-account relevance
- Pipeline attributed solely because a contact existed at the event

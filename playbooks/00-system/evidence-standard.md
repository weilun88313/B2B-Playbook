# Evidence standard

Label every important judgment as one of four types. Mixing them turns assumptions into process.

| Type | Meaning | Example |
|---|---|---|
| Fact | A dated record, public source, direct quote, or system event that can be checked | “The pricing page had no security link on 2026-03-12.” |
| Observation | A pattern from a limited sample | “Five of the last eight losses stalled at the security questionnaire.” |
| Assumption | An unverified belief that changes the next action | “CPOs may respond earlier than CFOs to event-triggered outreach.” |
| To validate | A question paired with a test that can close it | “Can an AE forward the comparison page into an evaluation thread?” |

## Promise to the reader

- Checklists and templates are starting methods, not guaranteed formulas.
- Compliance material is not legal advice; review it for the target jurisdiction before use.
- A “best practice” without an observable result should be downgraded to an assumption.
- When a source, benchmark, or platform behavior may expire, record the date checked.

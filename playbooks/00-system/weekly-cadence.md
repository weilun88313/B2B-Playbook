# Weekly operating cadence

The library works best as a learning loop, not a one-time workshop.

## Monday: choose one constraint

- Pick one live constraint: targeting, message, reply quality, event execution, or deal progression.
- Choose one module and no more than three metrics.
- Write the assumption you are testing this week.

## During the week: preserve evidence

- Record the source and date for facts.
- Keep replies, objections, meeting notes, and stage changes in their normal system of record.
- Do not change multiple variables in the same test unless the result can still be interpreted.

## Friday: review decisions, not activity

1. What changed in the evidence?
2. Which assumption became stronger, weaker, or false?
3. What should stop, continue, or change next week?
4. Does a template, checklist, or playbook need correction?

An active week ends with one documented decision and one next test, not a longer activity report.

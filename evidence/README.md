# Evidence

Field notes only. Each file:

- Date
- Channel (outbound, event, content, partner, other)
- Action taken
- Result (pipeline, meeting, nothing)
- Change for next time
- No customer PII, no unpaid source lists, no credentials

If there is no result yet, do not file a note. Put the idea back in the
playbook as a hypothesis.

Template: [`_template.md`](_template.md)

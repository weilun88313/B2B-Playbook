# Changelog

All notable changes will be documented here. Dates use `YYYY-MM-DD`.

## [0.1.0] — Unreleased

- Complete English playbooks for ICP, positioning, outbound, event-led growth, and enterprise sales
- A single English-first `playbooks/` information architecture
- A clearly separated Chinese orientation section in the root README

- Maintenance guidance now keeps one editorial owner while accepting structured feedback
- The former `en/` and `zh/` trees have been replaced by the canonical `playbooks/` tree

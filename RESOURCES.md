# GTM reading sources & operators

> A short list of newsletters, podcasts, and operators worth following—not a celebrity ranking.

**Directory release:** 16 sources · 2 layers (long-term GTM · AI watchlist)

**Last reviewed:** 2026-08-29

Playbooks say how to operate. [TOOLS.md](TOOLS.md) says which software fits a job. This page says **where a practitioner can keep learning** without treating a feed as a strategy.

It is not a paid-community membership pitch, not an affiliate list, and not a substitute for dated evidence on a tactic page. Subscribe to two or three. A twelfth newsletter will not invent an ICP.

## How this list is graded

The letters are this repository’s **editorial evidence bar**, not a popularity contest and not an audited citation count.

| Grade | Meaning |
|---|---|
| **A — Recurring** | Independently named by multiple operators, a durable public archive still cited in 2026, or a source this library already uses as primary evidence |
| **B — Practical** | A named operator uses it and can describe the job; useful, not yet a default |
| **C — Observe** | Thread mention, self-promo, vendor-adjacent, or mixed. Pilot before treating as canon |

A grade is not a command to buy a course, join a community, or copy last week’s play. Vendor blogs and “AI roundup” feeds are C until a specific article earns a place in a playbook source note.

Third-party links use `ref=b2b-playbook` only so destination sites can see this repository as the referrer. It is not an affiliate code.

## How to use this page

1. Pick **one** metrics voice (usually Kellblog or Clouded Judgement—not both as your operating system).
2. Pick **one** early-marketing or demand voice that matches the job this week (MKT1, Growth Unhinged, Refine Labs, Exit Five, or Heinz).
3. If you sell with humans, add **30MPC** or GTMnow. If you run RevOps, add RevOps Impact as B.
4. Keep AI feeds in a separate folder. They do not get a vote on ICP.

If a source disagrees with a published playbook, the playbook wins until you can cite a dated primary source and change the page.

## Sources and evidence boundary

This is an owner-maintained editorial directory. Grades synthesize recurring operator recommendations (including 2026 community threads) plus this library’s own citation practice. They are **observations**, not audited vote counts.

Inclusion is not an endorsement of a paid community, course, agency engagement, or tool the author sells. Pavilion is listed because its digest is a real operator feed; membership is optional.

When a playbook already names a source and date, that page’s evidence boundary still governs. Do not upgrade a newsletter anecdote into a verified use case.

# Templates

可直接复制和修改的 B2B 工作模板。

Reusable starting points for common B2B operating tasks:

- [`account-brief.md`](account-brief.md) — 账户研究与购买委员会
- [`experiment-log.md`](experiment-log.md) — 增长实验与结果记录
- [`opportunity-review.md`](opportunity-review.md) — 商机复盘与推进判断

模板不是表格填空游戏。只填写会影响判断和下一步行动的信息，
并为关键结论保留来源和置信度。

# 销售过程指标

以下健康区间来自公开的企业销售访谈，当作**待验证**，用来发现异常，不是承诺。

## 漏斗（合格之后）

| 阶段 | 健康信号 | 若偏离 |
|---|---|---|
| 对的人 → 合格商机 | 约一半到四分之三 | 入口层不对，或故事没有 alpha |
| 演示后 | 大约再掉一半 | 演示太早、框太宽、没共创 |
| 试点后仍前进 | 约 80% 应过 | 试点设计烂，或资格不够仍在「说服」 |
| 合格商机 → 签字 | 大约 **25–35%** | 明显高于此且赢很容易 → 先怀疑定价过低 |
| 输单次年回头 | 可到约 1/4 | 输单要记成熟度，不要当死人 |

「问题」人人会说，容易商品化。资格里更要听：**他们是否承认必须改变**。

## 过程健康（看销售做没做事）

- 首谈 → 正式演示之间的会次数（0 场共创 = 红灯）
- 每场演示是否可复述成不同的 20%
- 试点是否在倒排签字之后才开始
- 未签字是否已开工（应为 0）

## 不算数

- CRM 从「介绍」拖到「演示」就算进度
- 演示场次、试点登录人数
- 赢率 70% 还当骄傲（先查价）

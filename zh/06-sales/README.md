# 06 · 销售过程

企业销售不是 CRM 里的五段（介绍 → 演示 → 报价 → 合同 → 输赢）。那五段是**预测加权用的桶**。买家真正走过的，更接近十几步：约到会、非正式首谈、共同设计演示、小范围预演、正式演示、当场复盘、试点设计、定价、试点、合同与采购。

本模块写的是：**从第一次会议到签字**，怎么把信息差抓在自己手里，并让内部支持者觉得是他们在买，而不是被卖。

## 何时用

- 单笔足够大，需要执行层签字（常见门槛：约 10 万美元量级；流程与百万级同类，只是会议密度不同）
- 已经能约到执行层或 N-1（见 [01-icp](../01-icp/) 与 [03-outbound](../03-outbound/)）

## 何时不用

- 还在用脚本问 BANT，或一上来就要演示
- 成交额撑不起多次一对一（先把单价或范围想清楚）
- 把「演示做完」当成进度

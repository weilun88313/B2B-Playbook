# 清单：试点

## 放人进去之前

- [ ] 已与支持者倒排：成功后何时签字、采购/安全/法务谁要见面
- [ ] 若成功后仍要再等一个季度才可能上线 → **先不做试点**
- [ ] 成功标准已共写，不是「进去感受一下」
- [ ] 指定 3 件用户任务 + 如何衡量
- [ ] 用户 3–4 人，含支持者，**不含**把 C-level 当用户
- [ ] 不依赖对方数据则可卡 48–72 小时；必须集成则报价周期 + 费用可抵扣
- [ ] 演示后已与支持者一对一过定价（或明确的区间）

## 试点中 / 后

- [ ] 能看到实际使用路径（做了哪两件、哪一件没做）
- [ ] 卡住的人由支持者去问体验
- [ ] 试点后复盘与数据一致，不接受纯「挺好」

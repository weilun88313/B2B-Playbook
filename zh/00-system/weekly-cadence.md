# 一周节奏（最低配置）

一人或小团队够用。不是完整 RevOps 体系。

## 每周固定 90 分钟

| 分钟 | 做什么 | 产出 |
|---|---|---|
| 0–20 | 看漏斗：新对话、新商机、卡着的原因 | 三个数字 + 一个卡点 |
| 20–50 | 只推进一个模块的一个动作 | 发出的序列 / 更新的 ICP / 一场展的名单 |
| 50–70 | 过清单：发出前、页面上线前、展前 | 通过或卡住的项 |
| 70–90 | 写 5 行复盘 | 做了什么、结果、下周改什么 |

## 三个数字就够

1. 本周与 ICP 内经济买家或支持者的**新对话数**
2. 新出现的**合格商机**数（定义见术语表）
3. 唯一卡点（安全、无下一步、错角色、时机不对）

不要同时优化打开率、内容产量和展会数量。一周只认一个主动作。

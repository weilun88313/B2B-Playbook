# 证据标准

每条重要判断标成下面四类之一。混在一起写，会把假设当成流程。

| 类型 | 含义 | 写法 |
|---|---|---|
| 事实 | 可核对：日期、页面、原话、系统里的记录 | 「2026-03-12 官网定价页仍无安全入口」 |
| 观察 | 你看到的模式，样本有限 | 「最近 8 个未成交里有 5 个卡在安全问卷」 |
| 假设 | 尚未验证，但决定了你下一步 | 「CPO 比 CFO 更早响应展会相关邮件」 |
| 待验证 | 必须设计一次动作才能关闭 | 「对比页能否被 AE 直接转发进评估群」 |

## 对读者的承诺

- 清单和模板是方法，不是保证结果的公式
- 涉及合规的章节不是法律意见，上线前按目标国复核
- 没有结果的「最佳实践」应降级为假设

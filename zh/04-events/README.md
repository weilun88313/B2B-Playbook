# 04 · 活动型增长

把展会和行业会议当成**有截止日期的商机系统**，不是品牌摆摊。

精力分配启发式（不是 ROI 公式）：展前 40%、现场 20%、展后 40%。

## 何时用

- 已经决定花钱或派人去某场活动
- 或正在决定去不去

## 何时不用

- 用「行业都应该去」当理由，却说不出 ICP 账户会不会出现
- 成功标准是徽章数量

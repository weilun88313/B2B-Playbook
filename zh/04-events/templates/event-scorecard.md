# 模板：选展评分

总分建议 0–10。低于 5：默认不去或只做远程外联。5–7：派人、不买大展位。≥8：才讨论展位级别。

| 维度 | 0 | 1 | 2 | 分 |
|---|---|---|---|---|
| ICP 密度 | 几乎没有目标账户 | 有一些，混杂 | 名录/往届展商明显对得上 ICP | |
| 角色密度 | 只有市场/学生 | 有用户无买家 | 采购/运营/财务买家会出现 | |
| 触发 | 纯品牌见面 | 弱（「大家都会去」） | 强（签约、年度寻源、审计季） | |
| 可执行性 | 无法做展前名单 | 只有公开展商 | 能做展商+部分嘉宾/信号 | |
| 成本诚实 | 差旅+展位会挤掉本季度其他获客 | 可承受但伤 | 与预期商机匹配 | |

否决项（任一成立则不去）：无法说出 10 个可能出现的 ICP 账户；成功指标被规定为「扫徽章数」；无人能在展后 48h 跟进。

# 外联 SOP

## 准入

- ICP 能过滤名单（有取消资格）
- 每个进序列的账户有可观察触发，或明确降为 T2 分段假设
- 知道这封信写给哪个座位；写给支持者的信不是写给经济买家的信

## 步骤

### 1. 账户研究（T1 才做深）

复制 [account-research.md](templates/account-research.md)。T1：一对一。T2：同一触发共用一段假设，不编造个性化。T3：不进序列。

研究只回答：为什么是现在、谁会在乎、替代方案可能是什么、你要他们做的最小下一步。

企业单再加一条：**只写给执行层或 N-1。** 创始人打一把手，AE 打 N-1（钳形）。再往下不进主动序列。触达正文 2–3 句，讲 alpha 不是品类说明书。见 [two-sentence-outreach.md](templates/two-sentence-outreach.md)。他们被上百封信打过；不能让执行层兴奋，就不要做自上而下。

会议约到之后怎么开，见 [06-sales](../06-sales/)，不要首谈直接演示。

### 2. 写短序列

复制 [sequence.md](templates/sequence.md)。第一轮 5–7 个触点、两个渠道足够。每个触点必须多给一个回复理由：观察、问题、证据、或低摩擦下一步。

节奏跟购买情境走，不要为了「第 3 天必须发第 2 封」而发空信。

结束信必发。沉默也是结果。模板见 [breakup.md](templates/breakup.md)。

### 3. 发出前过两张清单

- [pre-send.md](checklists/pre-send.md)：角色、触发、第一句、下一步
- [compliance.md](checklists/compliance.md)：国家、退订、来源、能解释的系统

过不了就停，不要用「先发再说」绕过。

### 4. 分类回复

| 回复类型 | 动作 |
|---|---|
| 会议 | 进日历，补委员会未知项 |
| 请材料 | 只发对比页或一页约束，不发大礼包 |
| 不是我 | 问正确的人，不要继续教育此人 |
| 现在不要 | 记下触发，序列停 |
| 骂/投诉 | 立即停，按合规处理 |

### 5. 一周后只改一个变量

主题、第一句、目标角色、触发类型，一次只改一个。否则你不知道什么有效。

## 准出

- 序列里每个账户能指出触发和目标座位
- 有结束信
- 本周成功定义是「对话或明确拒绝」，不是打开率

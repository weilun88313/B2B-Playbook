# 03 · 外联

外联是对**相关账户里的相关的人**做有焦点的对话。邮件和职业网络是工具，不是策略。

## 何时用

- 已有 ICP 和触发因素
- 需要会议或明确的拒绝
- 名单不是买来的「邮箱宇宙」

## 何时不用

- 还不能说出经济买家与支持者的区别
- 把打开率当成功
- 目标国合规未核对（本章不是法律意见）

# 清单：发出前

对序列里的**每一封第一封**打勾。后续触点至少过「仍与触发有关」。

- [ ] 账户未命中取消资格
- [ ] 触发写在信里（日期、事件、公开事实），不是「贵司一直领先」
- [ ] 收件人座位明确：经济买家 / 支持者 / 技术买家；没有写给「尊敬的决策者」
- [ ] 第一句是对方的世界；产品名若出现，不在第一句
- [ ] 只有一个请求，且小（15 分钟、确认是否负责 X、指对的人）
- [ ] 没有附件（第一封）
- [ ] 没有「我们是领先的」「赋能贵司数字化」
- [ ] 退订或停止联系的方式可见（按渠道惯例）
- [ ] 发送域、姓名、落地页与合规清单一致

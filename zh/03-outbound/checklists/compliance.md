# 清单：合规最低项

**不是法律意见。** 跨境外联按目标国找合格顾问复核。此清单只防止「完全没想过」。

- [ ] 记录了联系人数据来源（官网、展会名片、对方主动留下、合法名录……）
- [ ] 记录了处理目的（要约会议 / 活动跟进）
- [ ] 目标国家已标在账户上，且该国 B2B 电邮/LinkedIn 规则已查过摘要（不是凭感觉）
- [ ] 能立即执行退出，且 24 小时内不再发
- [ ] 没有从说不清来源的「邮箱包」导入
- [ ] 发送基础设施（域名、认证、工具）你能在安全问卷里解释
- [ ] 内容没有虚假身份、没有假装已有关系
- [ ] 若用展会名片：是否仅用于该活动相关跟进，有没有超范围

过不了任何一项：不发送。

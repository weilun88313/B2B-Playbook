## 四格

| 格 | 你的定义 | 如何在名单里过滤 |
|---|---|---|
| 行业与用例 | | 关键词 / 名录 / 展会类型 |
| 买得起的规模 | | 人数、实体数、采购成熟度，选一个可观察代理指标 |
| 触发因素 | | 公开信号：招聘、展会、新闻、招标 |
| 取消资格 | | 明确排除规则 |

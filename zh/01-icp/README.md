# 01 · ICP 与购买委员会

把市场写成**账户和人**，而不是「所有对这个品类感兴趣的人」。

## 何时用

- 销售在追明显不会买的公司
- 内容或外联的「对象」每个渠道都不一样
- 有支持者、没有经济买家，却被算作商机

## 何时不用

- 还没有谈过 8 次以上真实对话（先访谈，不要空填评分表）
- 想用 ICP 证明「我们什么人都能服务」

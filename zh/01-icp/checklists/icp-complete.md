# 清单：ICP 是否写完

过关标准：每一项都能指到一页文档或表格，而不是「我们心里有数」。

- [ ] 用客户原话写了他们要完成的工作（不是功能列表）
- [ ] 写了谁付钱、谁用、谁能让交易失败
- [ ] 企业单进门层写清：只打执行层或 N-1，不把用户层当入口
- [ ] 有 5 条以上取消资格，且名单过滤时真的在用
- [ ] 触发因素可观察（招聘、展会、续约、公告、事故），不是「他们需要数字化」
- [ ] 至少 5 个真实接触过的账户拿来对过表
- [ ] T1 / T2 / T3 各有默认动作，T3 不进主动序列
- [ ] 新同事按同一张表能把同一账户打到同一档（允许差一档）
- [ ] 没有用「中小企业」「所有制造业」当 ICP

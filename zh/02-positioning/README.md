# 02 · 定位与官网

定位是最短、仍可信的解释：某个买家为什么要改现在的做法。

## 何时用

- 首页 10 秒内说不清卖给谁
- 销售每人一套说法
- 对比页在写功能表，没有写替代方案

## 何时不用

- ICP 还是空的（先做 01）
- 想用定位文档代替产品或证据

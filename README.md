# B2B-Playbook

面向 B2B 销售与增长的开放知识库：方法论、清单、模板和可抄示例。

An open knowledge base of B2B playbooks, checklists, templates, and worked examples.

由 [weilun88313](https://github.com/weilun88313) 独立整理。中文是主内容；英文目录已建好，正文后补。

## 你能直接拿走什么

第一期写厚五块。每一块都包含：何时用、SOP、清单、空白模板、一份填好的虚构示例、指标。

| 模块 | 拿走什么 |
|---|---|
| [ICP 与购买委员会](zh/01-icp/) | 评分表、委员会图、账户分级、填好的账户简报 |
| [定位与官网](zh/02-positioning/) | 一句话工作纸、10 秒检查清单、对比页大纲 |
| [外联](zh/03-outbound/) | 研究清单、触点序列、发出前合规检查、一条完整战役 |
| [活动](zh/04-events/) | 选展评分、展前/现场/展后清单、会后跟进 |
| [销售过程](zh/06-sales/) | 非正式首谈、演示共创、试点倒排、定价与采购清单 |

虚构示例统一用公司 **Helion**（供应商尽职调查软件），避免真实客户与真实产品。

## 怎么用

1. 先读 [zh/00-system/how-to-use.md](zh/00-system/how-to-use.md)
2. 用 [glossary.md](glossary.md) 对齐名词
3. 只选当前正在跑的那一块，从该目录的 `README.md` 进
4. 先抄 `templates/`，再对照 `examples/` 填自己的版本
5. 发出、上线或进会之前过一遍 `checklists/`

不要为了读完而读完。一次带走一个可验证的动作。

## 写作标准

- 区分事实、假设、待验证。见 [evidence-standard.md](zh/00-system/evidence-standard.md)
- 不公开个人信息、客户机密、未授权数据源或凭证
- 新增内容必须带：适用场景、不准用的场景、空白模板、至少一个示例

# B2B-Playbook

一个面向 B2B 销售与增长的开放知识库、方法论与工具集。

An open knowledge base of practical playbooks, templates, and tools for
building and operating B2B growth systems.

本项目由 [weilun88313](https://github.com/weilun88313) 独立整理和维护，
内容来自持续学习、实践、复盘与公开资料的再组织。

## 内容范围

- 市场定位与价值主张
- ICP、账户分层与购买委员会
- ABM、外联与机会管理
- 活动型增长与线下活动
- 内容、搜索与需求生成
- 销售支持、采购与安全评估
- 可复用模板、检查清单与轻量工具

## 核心原则

1. **从买家问题出发**：先理解触发因素、决策过程和替代方案，再选择渠道。
2. **从结果反推方法**：区分事实、假设、经验和待验证结论。
3. **方法必须可执行**：每个框架都应能转化为清单、模板或下一步动作。
4. **持续迭代**：记录什么做过、结果如何，以及下一次要改什么。
5. **尊重隐私与合规**：不公开个人信息、客户机密、私有数据源或凭证。

## 如何使用

### 方法论

- [Worldview](playbooks/worldview.md) — B2B 增长的基本判断
- [Positioning](playbooks/positioning.md) — 定位与价值主张
- [Pipeline](playbooks/pipeline.md) — ICP、账户与购买委员会
- [Outbound](playbooks/outbound.md) — 外联与跟进
- [Events](playbooks/events.md) — 活动型增长
- [Content](playbooks/content.md) — 内容与需求生成
- [Enablement](playbooks/enablement.md) — 销售支持与采购

### 模板与工具

- [`templates/`](templates/) — 账户简报、实验记录和运营模板
- [`tools/`](tools/) — 工具设计说明与计划（开发中）
- [`evidence/`](evidence/) — 脱敏后的实践记录与结果

如果你使用 AI agent，可以从 [`SKILL.md`](SKILL.md) 开始；它定义了
内容分类、阅读路径和输出规则。

### 推荐阅读顺序

先读 `worldview`，再读 `positioning` 和 `pipeline`，最后选择当前正在
执行的渠道。不要为了完成阅读而阅读；每次只带走一个可以验证的动作。

## 双语维护

中文和英文内容会逐步补齐。两种语言应共享同一套定义、结构和证据，
而不是互相独立地重复维护。
